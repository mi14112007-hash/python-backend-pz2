Все строки и ветви `src/app.py` покрыты отдельно тестами каждой
машины состояний. Независимая модель проверяет значения через API-клиент.
В общий отчёт включены также CLI, точка запуска сервера и сетевой клиент.
Покрытие дочернего процесса CLI не переносится в родительский coverage:
сам CLI проверен прямым вызовом функции и реальным запуском процесса.

Проверка асинхронности удерживает фоновую задачу событием и читает статус
`running` через API до освобождения исполнителя. Проверка SQLite закрывает
и повторно открывает базу, затем сравнивает сохранённый результат.
Четыре входных примера CLI успешно восстановлены побайтно.

Попытка запустить живой HTTP-сервер завершилась `Operation not permitted`:
среда запрещает открытие локального сетевого порта. Поэтому здесь не
подтверждён запуск `src.demo` через настоящий HTTP-сокет. Тестовый транспорт
Flask, XML, все обработчики, SQLite и subprocess проверены фактически.
Команда для самостоятельной сетевой демонстрации: `python -m src.demo`
после `python -m src.server` в другом терминале.

Git-репозиторий включает отдельные коммиты трёх этапов. Он не опубликован
на GitHub. Для сдачи нужно загрузить его в свой публичный репозиторий.
