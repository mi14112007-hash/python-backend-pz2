Все строки и ветви `src/app.py` покрыты отдельно тестами каждой
машины состояний. Независимая модель проверяет значения через API-клиент.
В общий отчёт включены также CLI, точка запуска сервера и сетевой клиент.
Покрытие дочернего процесса CLI не переносится в родительский coverage:
сам CLI проверен прямым вызовом функции и реальным запуском процесса.

Проверка асинхронности удерживает фоновую задачу событием и читает статус
`running` через API до освобождения исполнителя. Проверка SQLite закрывает
и повторно открывает базу, затем сравнивает сохранённый результат.
Четыре входных примера CLI успешно восстановлены побайтно.

Повторная проверка 6 ноября 2026 года подтвердила и настоящий HTTP:

Команда `python -m src.demo` успешно вызвала все восемь маршрутов,
дождалась фонового сжатия через subprocess и сохранила `results/demo.bz2`.
Побайтное совпадение распакованного файла с исходным подтверждено.
Тестовый сервер после демонстрации остановлен.

Общий отчёт выше относится к повторному полному запуску. Hypothesis
генерирует разные последовательности, поэтому покрытие вспомогательных
ветвей слоя данных может немного различаться между запусками. Отдельные
MBT-прогоны каждого этапа по-прежнему покрывают все строки и ветви
обработчиков `src/app.py` на 100%.
