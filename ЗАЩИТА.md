# Запуск и демонстрация на защите

Откройте папку проекта. На этом Mac подготовлено окружение `.venv`:
повторно устанавливать зависимости не требуется. Команды запускают Python
непосредственно из окружения, без ручной активации.

1. Запустите двойным щелчком `01-Запустить-сервер.command`.
   Оставьте терминал открытым. Адрес: http://127.0.0.1:5005.
2. Запустите `02-Демонстрация.command`. Клиент создаст пользователя,
   покажет поиск и изменение, отправит файл на сжатие, дождётся результата,
   проверит распаковку и покажет отчёт. Все восемь маршрутов будут вызваны.
   Архив появится в `results/demo.bz2`.
3. Запустите `04-Примеры-сжатия.command`: четыре примера CLI, размеры
   до/после и проверка восстановления исходных байтов.
4. Запустите `03-Тесты.command`: тесты Hypothesis и покрытие ветвей.
5. Остановите сервер сочетанием Control+C в его терминале.

## Что объяснить

- CLI получает путь входного файла, пишет Bzip2-поток в stdout.
- HTTP API принимает и возвращает XML; бинарные данные кодируются Base64.
- Обязательные заголовки: Accept: text/xml, Accept-Language: ru-RU.
- POST /api/register/query возвращает запрос, пока задача работает в фоне.
- Статусы Result: queued, running, done или failed.
- Фоновый исполнитель вызывает CLI через subprocess, а не сжимает в HTTP.
- SQLite содержит Person, Query, Result; SQL написан явно, без ORM.
- Отчёт возвращает уникальные пары locale/content для Query за последние
  девять минут; точная нижняя граница в выборку не входит.
- Обе машины состояний Hypothesis сравнивают API с отдельной моделью.

В браузере не предусмотрен графический интерфейс: это работа с HTTP API.
Для демонстрации используются Python-клиент и XML-запросы из README.
Тестовый режим `--fake` не выполняет настоящее сжатие; для защиты запускайте
обычный сервер. Полное описание: README.md.

## Если нужно запустить вручную

Откройте терминал в этой папке:

```sh
./.venv/bin/python -m src.server
```

Во втором терминале в той же папке:

```sh
./.venv/bin/python -m src.demo
```

На другом компьютере сначала создайте новое окружение по README.
Подготовленное окружение рассчитано на текущий Mac и установленный Python.
